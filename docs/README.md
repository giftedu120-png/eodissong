# 어디쏭 정적 HTML

`index.html` 하나에 화면, 스타일, Mock 데이터와 동작 코드가 모두 포함되어 있습니다.

로컬에서 위치 기능까지 확인하려면 이 폴더에서 웹 서버를 실행하세요.

```bash
python -m http.server 8080
```

그런 다음 `http://localhost:8080`을 엽니다. 파일을 직접 더블클릭해도 대부분의 기능은 동작하지만 브라우저 보안 정책상 위치 권한은 사용할 수 없습니다.

지도와 장소 사진은 인터넷 연결이 필요합니다. GitHub Pages는 `docs/` 폴더의 이 파일을 그대로 제공합니다.
