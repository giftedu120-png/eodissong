# 어디쏭 (eodissong)

사진, 장소 이름, 현재 위치로 여행지를 발견하고 상세 정보로 이어지는 모바일 우선 여행 웹앱입니다. 장소·지도·미션은 외부 API 키 없이 확인할 수 있는 Seed/Mock Provider를 사용하고, 사진은 브라우저에서 무료 AI 모델로 분석합니다.

이번 버전에는 사용자가 명시적으로 동의한 뒤 실제 Geolocation 좌표를 사용하는 지도, 길찾기, AI 여행 미션이 포함됩니다.

## 실행

Node.js 22.13 이상에서 `npm install` 후 `npm run dev`를 실행합니다.

## 구조

- `app/page.tsx`: 사진 검색, 이름 검색, 주변 명소의 동일 비중 첫 화면
- `app/place/[id]/page.tsx`: 장소 사진, 설명, 주소, 지도, 길찾기·미션 진입점
- `app/providers/types.ts`: 장소·이미지 분석·지도 Provider 계약
- `app/providers/browser-vision.ts`: Transformers.js/CLIP 기반 브라우저 내 무료 사진 분석 Adapter
- `app/providers/mock.ts`: 부산 명소를 사용하는 Mock 구현
- `app/explore/page.tsx`: 실제 좌표 중심의 미션 지도, 사진 완료, 포인트
- `app/directions/page.tsx`: 현재 위치·주소·장소 기반 길찾기와 편의시설
- `app/components/LocationConsentModal.tsx`: 위치 활용 안내 및 직접 입력 대체 흐름
- `app/components/TravelMap.tsx`: OpenStreetMap 기반 현재 위치·경로·미션 마커 지도
- `docs/index.html`의 `#/course`: 출발지·경유지·최종 목적지를 하나의 상세 주소·장소 검색으로 설정하고 실제 도로 최단 순서를 계산하는 정적 AI 추천 코스

## 가정

- 현재 공개 버전은 부산의 검증 가능한 실제 관광 명소 30곳을 Seed 데이터로 제공합니다.
- 사진 분석은 브라우저에서 Transformers.js의 `Xenova/clip-vit-base-patch32` 모델을 실행해 등록된 부산 명소 30곳의 시각 특징 문장과 비교합니다. 상위 1곳을 우선 추천하고 2·3위 후보를 접어서 제공합니다.
- 사진은 분석을 위해 서버로 업로드하지 않습니다. 첫 분석 때 약 90MB 이상의 모델 파일을 내려받아 브라우저 캐시에 보관하므로 네트워크와 기기 성능에 따라 시간이 걸릴 수 있으며, 사진 검색과 미션 사진 심사 중 `사진 분석에는 일정 시간이 소요됩니다` 안내를 표시합니다.
- 후보 일치도는 등록된 30개 장소 사이의 상대적인 모델 점수이며 실제 위치일 확률이나 정확도 보증값이 아닙니다. 후보 점수가 낮거나 비슷하면 불확실 안내를 표시합니다.
- 위치 권한은 사용자가 기능 버튼과 동의 버튼을 누른 뒤에만 요청합니다. `watchPosition`은 사용하지 않으며 마지막 좌표는 탭의 세션 저장소에만 보관합니다.
- 정적 공개 버전의 길찾기와 추천 코스는 OSRM의 OpenStreetMap 도로망을 사용합니다. 교통 상황·보행 속도·서비스 데이터 차이로 실제 소요 시간과 다를 수 있어 두 결과 화면에 `이는 예상 시간이며, 실제와 맞지 않을수도 있습니다` 안내를 표시합니다.
- 미션 완료 기록과 누적 포인트는 MVP 범위에서 브라우저 `localStorage`에만 저장됩니다. 포인트는 완료 기록과 별도로 저장되어 미션 초기화 후에도 유지됩니다.
- 상단 계정 버튼은 로그아웃 상태에서 `로그인`, 로그인 상태에서 같은 크기의 누적 포인트 버튼으로 표시됩니다. 간편 로그인은 이름과 로컬 아이디, 게스트 모드는 이름만 사용하며 비밀번호를 수집하지 않습니다. 로그인 사용자 점수는 10명의 Seed와 함께 브라우저 내 Mock 랭킹으로 정렬됩니다.
- 로그인·게스트 세션과 랭킹은 현재 브라우저에만 저장되는 정적 MVP입니다. 실제 전체 사용자 랭킹, 여러 기기 간 동기화, 상품 지급을 운영하려면 서버 인증, 서버 검증 포인트 원장, 랭킹 API가 필요합니다.
- 미션 초기화는 완료·진행 상태만 지우며 같은 기기와 브라우저에서 24시간에 한 번만 가능합니다. 마지막 초기화 시각 역시 브라우저에 저장됩니다.
- 미션 사진은 장소별 심사 문장과 무관 사진 기준을 무료 브라우저 CLIP 모델로 비교하며, 미션 일치도가 60% 이상일 때만 완료와 포인트를 기록합니다. 60% 미만이면 완료 처리 없이 미션 카드로 돌아가 재촬영을 안내합니다.
- 미션 일치도 역시 프롬프트 사이의 상대 점수이므로 실제 현장 인증이나 부정 사용 방지를 보증하지 않습니다. 정확한 운영 심사가 필요하면 검증 데이터로 보정한 전용 Vision Adapter가 필요합니다.
- AI 미션은 검증된 Seed 장소만 거리순으로 구성하며 존재하지 않는 장소를 생성하지 않습니다.
- 부산 추천 Seed에는 해변, 시장, 공원, 전망대, 사찰, 박물관, 생태·문화공간 등 30곳이 포함되며 현재 위치에서 80km 이내 장소를 우선합니다.
- 각 부산 명소에는 비짓부산과 공개 지도에서 확인한 실제 카페 Seed를 최소 2곳씩 명시적으로 연결합니다. 지정 카페를 먼저 표시하고 나머지 후보는 거리순으로 보충합니다. 매장명과 영업 상태는 바뀔 수 있으므로 실제 서비스 연결 시 장소 Provider로 주기적인 갱신이 필요합니다.
- 지도와 장소 사진은 공개 웹 리소스를 사용하므로 오프라인에서는 표시되지 않을 수 있습니다.
- 상단 번역 선택기에서 한국어, 영어, 일본어, 중국어(간체), 대만어(번체)를 전환할 수 있으며 선택값은 브라우저 `localStorage`에 저장됩니다. 정적 다국어 사전을 사용하므로 번역 API 키나 비용이 필요하지 않습니다.
- AI 추천 코스는 OSRM 도로 거리표와 동적 계획법으로 선택한 경유지의 최단 방문 순서를 계산합니다. 최종 목적지는 항상 마지막에 고정하며, 카페 방문을 선택하면 검증된 카페 Seed 한 곳도 경유지 최적화에 포함합니다.
- 추천 코스에는 사용자가 선택하지 않은 검증된 부산 Seed 명소 중 기존 이동 구간의 추가 이동이 짧은 한 곳을 `AI 추천` 경유지로 포함합니다. 카페 선택 시 카페도 `AI 추천 카페`로 표시하며, 결과 화면에서 AI가 추가한 명소와 카페만 삭제할 수 있습니다. 삭제하면 남은 장소를 기준으로 실제 도로 거리와 예상 시간을 다시 계산합니다.
- 코스 생성 중에는 AI 추천 선정, 실제 도로 거리 비교, 최종 도로 경로 생성 단계를 경과 시간과 함께 표시합니다. 도로 거리표 서비스가 지연되거나 실패하면 거리 기반 대체 순서로 계속 진행하고, 최종 도로 경로 요청은 한 번 자동 재시도합니다.
- 추천 결과의 `상세 경로 보기`는 출발지와 각 경유지·최종 목적지 사이를 구간별로 나누어 도로 안내, 거리, 예상 시간을 제공합니다. 좌우 화살표로 이전·다음 구간을 이동하며, 지도에는 선택한 구간의 실제 도로 형상이 강조됩니다.
- AI 추천 경유지와 대체 순서 계산은 정적 페이지에 정의된 공통 Haversine 거리 함수 `distance`를 사용합니다. 코스 생성 전에 진행 화면을 먼저 렌더링한 다음 계산을 시작합니다.
- AI 추천 코스의 `설정 코스 초기화` 버튼은 설정한 출발지, 경유지, 최종 목적지, 카페 방문 선택과 계산 결과를 모두 비우며 포인트와 미션 기록에는 영향을 주지 않습니다. 초기화 후에도 경유지와 최종 목적지 선택창을 포함한 전체 코스 편집 화면은 그대로 유지됩니다.
- 코스의 상세 검색은 일치하는 등록 장소를 `<관광 명소>`, OpenStreetMap Nominatim 결과를 `<추가 검색 결과>`로 나누어 한 목록에 표시합니다. 등록 명소를 먼저 모두 보여준 뒤 외부 검색 결과를 이어서 제공하며, 약 5개 항목 높이의 고정된 결과 창에서 스크롤해 직접 선택해야만 경유지 또는 최종 목적지로 등록됩니다. 부산 범위의 명소명·동·도로명·역·건물명처럼 구체적인 검색어가 필요합니다.
- 주변 명소 지도에서는 설정된 `내 위치`와 추천 카드의 `<추천된 주변 명소>` 표지를 분리해 표시합니다.
- 상단에서는 미션 지도 바로가기 대신 로그인 또는 누적 포인트 버튼을 모바일에서도 표시합니다. 포인트 버튼을 누르면 현재 점수와 1~10위 랭킹을 확인할 수 있습니다. 미션 장소 카드는 닫기 버튼을 제공하고, 미션 수행 후 촬영·파일 업로드 선택지는 미션 설명 바로 아래에 표시됩니다.

## 실제 API 연결 시 환경 변수 예시

클라이언트 코드에 키를 노출하지 않고 서버 측 Adapter에서만 사용해야 합니다.

```env
PLACES_API_KEY=
MAPS_API_KEY=
VISION_API_KEY=
TRANSLATION_API_KEY=
```

현재 브라우저 사진 분석에는 `VISION_API_KEY`가 필요하지 않습니다. 향후 서버 기반 상용 Vision Adapter로 교체할 때만 사용합니다.
